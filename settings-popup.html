AI Notepad

Automatically capture session notes from AI responses. Notes are stored per-chat and reinjected into future messages so the AI remembers what happened.

The writing AI includes <dle-notes> tags in its response. No extra API calls — notes are extracted from the response text. Best with flagship models (Claude Opus/Sonnet, GPT-4o). Smaller models may not follow the format.
After each response, DLE sends the text to your AI Search connection to extract session notes. Works with any writing model — the extraction uses a separate, reliable call. Visible "Note to self:" prose is automatically stripped. Costs one extra API call per message.

Diagnostics

Export a self-contained diagnostic report to share when reporting bugs. The file is anonymized (API keys, IP addresses, hostnames, user paths are pseudonymized) and is designed to be readable by a flagship LLM for self-service triage. You're encouraged to verify the file before sharing.

Export Diagnostics

Token Estimation

Token counts shown throughout DLE (budget bars, entry sizes, injection totals) are estimates based on ~4 characters per token. This is accurate for typical English text but may undercount for non-Latin scripts, code blocks, or highly punctuated content. For precise counts, consult your API provider's tokenizer.
